Cheatsheet CSS3

Referencia rápida de selectores, modelo de caja, layouts modernos y diseño adaptable.

1. Selectores, cascada y especificidad

Definen a qué elementos se aplica cada regla y cuál prevalece cuando hay conflictos:

/* Etiqueta, clase e id */
p { color: #2d3748; }
.tarjeta { border-radius: 8px; }
#destacado { font-weight: 700; }

/* Variables CSS (Custom Properties) */
:root {
  --color-acento: #ff6b6b;
}

2. Modelo de caja y box-sizing

Todo elemento se representa como una caja compuesta por contenido, relleno, borde y margen:

  • padding: espacio interior entre el contenido y el borde.
  • border: línea que rodea la caja.
  • margin: espacio exterior que separa la caja de otras.
*,
*::before,
*::after {
  box-sizing: border-box;
}

.caja {
  width: 300px;
  padding: 16px;
  border: 2px solid #4ecdc4;
  margin: 24px auto;
}

3. Flexbox y CSS Grid

Flexbox alinea elementos en una dimensión (fila o columna); Grid organiza rejillas en dos dimensiones (filas y columnas):

/* Flexbox: centrar y separar en fila */
.barra {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

/* CSS Grid: rejilla adaptable de tarjetas */
.rejilla {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}

4. Responsive design y media queries

Permiten adaptar el diseño al tamaño de pantalla (enfoque mobile-first con min-width):

/* Base en móvil */
.menu {
  display: none;
}

/* A partir de 768px (tablet y escritorio) */
@media screen and (min-width: 768px) {
  .menu {
    display: flex;
    gap: 24px;
  }
}
