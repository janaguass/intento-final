Cheatsheet JavaScript

Referencia rápida de variables, funciones, arrays y objetos, DOM, eventos y módulos ES.

1. Variables, tipos y funciones

Usa const por defecto y let cuando el valor vaya a reasignarse:

const nombre = "Jana";
let contador = 0;

function sumar(a, b) {
  return a + b;
}

const multiplicar = (a, b) => a * b;

2. Arrays y objetos

Estructuras habituales para guardar colecciones y datos agrupados por clave:

const lenguajes = ["HTML", "CSS", "JS"];
const etiquetas = lenguajes.map((item) => item.toLowerCase());

const tarjeta = {
  titulo: "CSS3",
  url: "cheatsheet-css.html",
};

3. Selección y manipulación del DOM

Permiten buscar elementos en el documento y actualizar su contenido o clases:

const boton = document.querySelector("#dark-mode-btn");
const contenedor = document.getElementById("cheatsheets");

document.body.classList.toggle("dark-mode");
contenedor.innerHTML = "<p>Contenido actualizado</p>";

4. Eventos y módulos ES

Escucha interacciones del usuario y divide el código en archivos con import y export:

// En un módulo (por ejemplo, cheatsheetsList.js)
export const cheatsheets = [
  { id: "html", titulo: "HTML5", enlace: "cheatsheet-html.html" }
];

// En el archivo principal (<script type="module" src="./js/main.js"></script>)
import { cheatsheets } from "./cheatsheetsList.js";

boton.addEventListener("click", () => {
  console.log("Total de cheatsheets:", cheatsheets.length);
});
