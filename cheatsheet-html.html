Cheatsheet HTML5

Referencia rápida de estructura y etiquetas fundamentales de HTML5.

1. Estructura básica del documento

Todo documento HTML5 empieza declarando el tipo de documento y envolviendo el contenido en <html>.

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Título de la página</title>
  </head>
  <body>
    <!-- Contenido visible -->
  </body>
</html>

2. Etiquetas semánticas

Describen el propósito de cada bloque para accesibilidad, SEO y claridad del código:

  • <header>: cabecera introductoria o de navegación.
  • <nav>: grupo principal de enlaces de navegación.
  • <main>: contenido principal y único de la página.
  • <section>: agrupación temática con un encabezado.
  • <article>: contenido independiente y reutilizable (como una tarjeta o entrada).
  • <aside>: información complementaria o lateral.
  • <footer>: pie de página o de sección.

3. Textos, listas, enlaces e imágenes

Elementos habituales para estructurar el contenido dentro de cada sección:

<h2>Subtítulo</h2>
<p>Texto normal con <strong>importancia</strong> y <em>énfasis</em>.</p>

<ul>
  <li>Elemento sin orden</li>
  <li>Otro elemento</li>
</ul>

4. Formularios y controles HTML5

Permiten recoger datos del usuario y aplicar validación básica directamente desde el navegador:

<form action="#" method="POST">
  <fieldset>
    <legend>Contacto</legend>

    <label for="nombre">Nombre</label>
    <input type="text" id="nombre" name="nombre" required />

    <label for="correo">Email</label>
    <input type="email" id="correo" name="correo" required />

    <label for="mensaje">Mensaje</label>
    <textarea id="mensaje" name="mensaje" rows="4"></textarea>

    <button type="submit">Enviar</button>
  </fieldset>
</form>
